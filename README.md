# Melly's Recycling: Organics Site Finder

Heat maps for siting a 390,000 ton-per-year organics facility: Miami-Dade (buy vs. lease, compost vs. transfer vs. MRF) and an inland hub on Florida's rail lines (FEC, CSX, SCFE). Includes the South Miami RFP PW2026-04 summary, lease comps and the state, county and zoning rules.

The whole site is one self-contained file, `index.html`.

## Put it online with GitHub Pages

1. Create a new public repository on github.com (for example `compost-site-finder`).
2. Click **Add file → Upload files**, drag in `index.html` and this README, and commit.
3. Go to **Settings → Pages**. Under "Build and deployment", pick **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/compost-site-finder/`.

Add `#florida` to the end of the URL to open straight to the Florida map.

Screening tool only. Map layers are approximations and listings are asking figures as of Nov 2026.
